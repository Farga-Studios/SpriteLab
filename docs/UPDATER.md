# Suite.Updater — release contract
Distribution: public ManubeX/SpriteLab-Downloads, source remains private. Stable release assets update.json, update.json.sig (raw RSA PKCS#1 v1.5 SHA-256 signature over exact manifest bytes), SpriteLab-X.Y.Z-win-x64-setup.exe. JSON snake_case keys product (SpriteLab), channel (stable), version (X.Y.Z), file_name, bytes, sha256, notes. Pin public PEM in src/SpriteLab.App/Updates/PublicKey.pem before building a baseline. Never commit private key or send it in chat. Generate offline with openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:3072 -out private.pem; export public via openssl pkey -in private.pem -pubout -out PublicKey.pem; sign openssl dgst -sha256 -sign private.pem -out update.json.sig update.json. Keep private key securely offline and backed up. No automatic publication. The current client refuses checks without pinned key, verifies signature, validates product/channel/version/file name/length/hash and downloads to LocalAppData/SpriteLab/Updates. UI currently requires manual installer launch after closing. Automatic handoff, portable updates, restart and rollback still need implementation and testing. Do not mark delivery accepted until baseline-to-newer test, corrupt signature/hash, offline, cancellation, permissions, dirty projects and rollback pass. Authenticode signing is separate.
