# SpriteLab 0.2.6 — candidata Windows x64

Extrae todos los archivos del ZIP en una carpeta nueva y ejecuta SpriteLab.App.exe. No necesita el SDK de .NET ni Python. No copies sólo el ejecutable: necesita sus archivos adjuntos. Mantén los proyectos de sprites fuera de la carpeta de la aplicación.

El artefacto de GitHub Actions es privado y temporal (14 días). El SHA-256 corresponde al ZIP interior. No es una release pública ni un instalador firmado. La prueba automática de arranque no abre la ventana; verifica manualmente la interfaz, importación, selección de celdas, cambio de recursos, guardado y reapertura.

Quitar un recurso no elimina su archivo original ni las copias de fuentes existentes. La recuperación desde backup todavía no está disponible. La reproducción permite FPS y duración individual. Los proyectos guardados en esquema 5 requieren SpriteLab 0.1.3 o posterior.
