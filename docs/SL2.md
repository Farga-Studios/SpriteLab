# SL2 — Animations

0.1.2: row-based named clips with stable clip and sheet UUIDs and ordered cell indices. This is a transitional adapter, not the final ADR-SL-002 Frame-ID model. Grid changes and sheet removal blocked while referenced. Schema 2 writes, schema 1 reads; older applications reject schema 2. Keep a copy before saving with the new version. Next: direction tracks and migration to full domain IDs, playback, timing, onion skin. Manual checks: create from row, select across sheets, save/reopen, remove clip, blocked grid change. CI pending.

0.1.3: multiple direction tracks, free case-sensitive labels, same sheet per clip. Assigning first named track replaces the implicit none track; assigning an existing label replaces its row. Cannot remove the final track. Schema 3 writes, 1/2 reads; old clips remain intact on load. Cell-index adapter retained, full Core frame-ID model deferred. Test assigning different rows, switching directions, saving/reopening and old-schema loading. CI pending.

0.1.4: selected direction plays at fixed 8 FPS using UI dispatcher timer. Cursor preserves repeated occurrences, supports pause, stop, loop and stepping. Clicking a sheet cell exits clip playback; reselect the clip/direction to return. No schema change. Timing is preview-only and timer precision is not guaranteed. Dedicated clip timeline, custom FPS, duration editing and full Core frame-ID mapping remain pending. CI and manual checks pending.

0.1.5: per-track FPS (1–60; default 8), optional per-occurrence duration (1–60000 ms); blank uses FPS default. Apply while paused; repeated cells can have different duration. Schema 4 writes, 1–3 reads. Reassigning a row resets its timing. UI timer is not a precise gameplay clock. Full Core Frame-ID mapping remains pending. CI and GUI verification pending.

0.1.6: onion skin overlays previous/next occurrences over current cell at 10–80% opacity (default 35%), with same cell-local origin. Loop checkbox controls wrapping; one-frame tracks have no neighbors. Overlays hidden during playback, view-only. No tint, alignment correction or schema change. Full Core Frame-ID model and dedicated clip timeline still pending. CI and manual checks pending.

0.2.0 candidate: occurrence-based thumbnails and clicking, monotonic clock with accumulated variable durations. Pause restarts current frame duration on resume. Schema unchanged. Full Core ID migration, keyboard and DPI acceptance remain outstanding. Do not declare SL2 approved until CI and manual evidence per ADR 007.

0.2.1.1: schema 5 canonical persisted FrameDocument (stable frame IDs, sheet/cell source, ordered frame-ID tracks, occurrence timings). Core SpriteProject validation now used at persistence boundary. Legacy schemas 1–4 read unchanged; save upgrades and previous version cannot open new schema. IDs deterministic for immutable source cells; UI remains cell-based; arbitrary frame source edits, unreferenced frame retention and full Core timing representation are deferred until an explicit editing model. SL2 remains unaccepted pending CI/manual verification and usability work.

0.2.1.2: Core tracks now carry FPS and per-occurrence durations; UI supports sequence text editing, keyboard playback/navigation and zoom/pan. Sequence editing retains durations by matching repeated occurrences in original order. Schema 5 unchanged. Remaining: migration integration tests, CI and manual Windows/DPI validation; viewer grid projection remains limited to immutable original cells.
