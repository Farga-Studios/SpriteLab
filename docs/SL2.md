0.1.3: multiple direction tracks, free case-sensitive labels, same sheet per clip. Assigning first named track replaces the implicit none track; assigning an existing label replaces its row. Cannot remove the final track. Schema 3 writes, 1/2 reads; old clips remain intact on load. Cell-index adapter retained, full Core frame-ID model deferred. Test assigning different rows, switching directions, saving/reopening and old-schema loading. CI pending.

0.1.4: selected direction plays at fixed 8 FPS using UI dispatcher timer. Cursor preserves repeated occurrences, supports pause, stop, loop and stepping. Clicking a sheet cell exits clip playback; reselect the clip/direction to return. No schema change. Timing is preview-only and timer precision is not guaranteed. Dedicated clip timeline, custom FPS, duration editing and full Core frame-ID mapping remain pending. CI and manual checks pending.
