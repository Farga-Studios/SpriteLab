# SL1 — Incremental viewer delivery

0.0.6: temporary single-sheet PNG preview, read-only import, checkerboard, 100–800% integer zoom and scrolling. Limits: 64 MiB compressed, 8192 px per dimension, 16,777,216 pixels. Header checks are not full PNG validation; the Avalonia decoder must succeed. Preview is not a persistent project and is not a guarantee of straight RGBA preservation for future export.

Next: configurable grid and cell selection, persistent project folder with protected source copies, infrastructure tests, Windows portable artifact after successful CI. No engine or Python dependency.

0.0.7: grid configuration defaults to 48 × 48; exact divisibility required. Selection uses zero-based row-major indices internally and one-based labels in the UI. Grid lines can be hidden; selection remains visible. Lines spaced below four DIPs are omitted to limit clutter. Seven new Core tests cover hit testing and bounds. Cells are temporary view selections, not persistent Frame objects; no durations or anchors assigned. Manual check: rectangular grid at multiple zooms, edge clicks, invalid dimensions, next/previous, grid toggle and reimport reset. Next: project persistence.

0.0.8: persistence backend only. Manifest records sheets and optional grid dimensions; full frame/clip schema and UI integration are still pending. Source paths are derived from UUIDs; original files are not overwritten. SHA-256 detects source changes; manifest revision prevents accidental overwrite; cooperative lock and File.Replace protect normal local use. Explicit recovery UI, full PNG decode validation, cleanup of orphan sources, filesystem race hardening and infrastructure tests remain pending. No verified CI result for the preceding fix was available through the connector; owner requested continuation. No phase closure claimed.

0.0.8 UI integration: reconciled pending viewer commit with existing ProjectStore; one persistent schema only, sources/{uuid}.png with SHA-256 in manifest. ViewerWorkspace adapts temporary in-memory resources to ProjectStore, which retains the cooperative writer lock and revision checks. New source copies are staged and moved without overwriting; failed saves may leave complete unreferenced copies. Viewer limits: 64 sheets / 256 MiB compressed. Open decodes resources before replacing the current workspace; per-sheet grid configuration is saved. No full frame/clip persistence or backup recovery UI yet. Manual and CI verification pending. No force push performed.

0.1.0 candidate: clickable bounded thumbnail strip (row-major grid, not animation clips), resource rename/remove without source deletion, and private portable artifact with SHA-256. Deferred: resource thumbnails, middle-button panning, fractional fit, grid inference, full domain persistence and recovery UI. Candidate is not a public release; manual package launch and regression checks still required.
